# gold-miner/mobile-shell Specification

## Purpose
定义黄金矿工在移动设备上的呈现与运行方式：响应式画布、触摸输入、音效震动、PWA 安装与离线缓存，以及无需服务器的单文件运行包，确保玩家可以直接在手机上流畅游玩。

## Requirements

### Requirement: 响应式游戏画布
系统 SHALL 使用固定逻辑分辨率渲染游戏，并按设备像素比缩放到可用视口；画布 MUST 保持完整可见，不得出现页面滚动条或横向溢出。布局 MUST 适配刘海屏安全区和横竖屏切换。

#### Scenario: 竖屏手机
- **WHEN** 页面在 390×844 的竖屏设备打开
- **THEN** 游戏区域完整显示，HUD 不被刘海或底部手势条遮挡

#### Scenario: 横屏切换
- **WHEN** 玩家旋转设备到横屏
- **THEN** 画布按比例重新适配，游戏状态不重置，界面无溢出

#### Scenario: 高像素密度
- **WHEN** 设备像素比为 3
- **THEN** 系统按不超过 2 的像素比渲染，以兼顾清晰度与性能

### Requirement: 触摸与键盘输入
系统 SHALL 支持在游戏区域任意位置点击或触摸发射钩子，触摸响应 MUST 无 300 毫秒点击延迟，且不得触发页面缩放或滚动。桌面端 SHALL 支持空格发射、`P` 暂停、`M` 静音。

#### Scenario: 手机触摸发射
- **WHEN** 玩家手指触碰游戏区域
- **THEN** 钩子立即发射，页面不滚动、不缩放

#### Scenario: 键盘快捷键
- **WHEN** 桌面玩家按下空格、`P` 或 `M`
- **THEN** 分别执行发射、暂停切换和静音切换

### Requirement: 音效与触觉反馈
系统 SHALL 使用 Web Audio 合成音效，包括发射、抓取、结算、爆炸和失败；首次用户手势 MUST 解锁音频上下文。静音状态 MUST 持久化，设备支持振动时 SHALL 在抓取和爆炸时提供短震动。

#### Scenario: 首次交互解锁音频
- **WHEN** 玩家首次点击开始游戏
- **THEN** 音频上下文被创建并恢复，后续音效可正常播放

#### Scenario: 静音持久化
- **WHEN** 玩家关闭音效后刷新页面
- **THEN** 音效保持关闭，界面按钮显示静音状态

#### Scenario: 不支持振动
- **WHEN** 设备或浏览器不提供 `navigator.vibrate`
- **THEN** 游戏不报错，仅跳过震动反馈

### Requirement: PWA 安装与离线运行
系统 SHALL 提供 Web App Manifest 与 Service Worker，支持添加到主屏幕并以独立窗口启动。Service Worker MUST 缓存应用外壳，在首次成功加载后支持离线启动，并在版本更新时清理旧缓存。

#### Scenario: 安装到主屏幕
- **WHEN** 玩家在支持的移动浏览器中选择“添加到主屏幕”
- **THEN** 应用以独立窗口启动，图标与名称正确显示

#### Scenario: 离线启动
- **WHEN** 设备在首次加载后断开网络并重新打开应用
- **THEN** 游戏仍可从缓存加载并开始游玩

#### Scenario: 版本更新
- **WHEN** 应用发布新的缓存版本
- **THEN** Service Worker 激活后删除旧版本缓存，避免无限占用存储

### Requirement: 单文件离线包
系统 SHALL 提供构建脚本，将 HTML、CSS、JavaScript 与必要资源内联为一个独立的 `dist/gold-miner.html`。该文件 MUST 在不启动服务器、不访问网络的情况下直接打开并完整运行。

#### Scenario: 手机直接打开单文件
- **WHEN** 玩家把 `dist/gold-miner.html` 传到手机并用浏览器打开
- **THEN** 游戏正常渲染和操作，控制台无资源加载失败

#### Scenario: 重复构建
- **WHEN** 开发者连续运行两次构建脚本
- **THEN** 每次都能生成可运行的单文件，且不依赖上一次的构建产物

### Requirement: 可访问性与性能
系统 SHALL 为所有可交互按钮提供不小于 44×44 CSS 像素的触控区域和可读的 `aria-label`。游戏循环 MUST 以每秒 60 帧为目标，切到后台时暂停渲染；在中等性能手机上不得出现持续掉帧或内存增长。

#### Scenario: 按钮触控尺寸
- **WHEN** 使用辅助技术或手指操作暂停、静音、商店按钮
- **THEN** 每个按钮的点击区域至少为 44×44 CSS 像素，并带有可读标签

#### Scenario: 页面隐藏时暂停
- **WHEN** 浏览器标签页或应用进入后台
- **THEN** 渲染循环与计时器暂停，返回时从暂停状态恢复
